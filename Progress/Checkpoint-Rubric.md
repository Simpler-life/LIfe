# Learning Checkpoints — Evidence and Passing Rules

This rubric applies to CS61A, AI Foundations and UDL. A completed reading checkbox **does not** mean the corresponding concept is mastered.

## Four gates
1. **Recall (R)** — without notes, explain the topic, define assumptions, and draw an example (>= 80% of key ideas correct, no fundamental misconception).
2. **Practice (P)** — independently solve core problems, run tests, and explain the logic. For CS61A use the course's provided tests where available. Do not publish solutions to graded tasks.
3. **Transfer (T)** — solve one altered/unseen instance or justify a counterexample without step-by-step AI help.
4. **Reflection (F)** — write 3–5 sentences: what worked, what failed, one corrected misconception, and next action.

A checkpoint is **PASSED** only when R + P + T meet the criteria and F is recorded; otherwise mark **RETRY**, revisit a specific prerequisite, and attempt a *different* question. AI may ask questions and identify errors after your first independent attempt.

## Milestones
| Milestone | Target evidence | Exit criteria |
| --- | --- | --- |
| CP-01 Python fundamentals | functions, loops, recursion, list problems | 3 unseen problems, each runnable, tests pass, explain environment/calls |
| CP-02 Graph search | BFS/DFS/UCS/A* hand trace + runnable search | correct exploration order and path-cost explanation; alter one graph and repeat |
| CP-03 Adversarial search | minimax, alpha-beta, UCB/MCTS worked trees; playable agent | correct viewpoint/sign handling, legal moves, game termination, reproducible 10+ test games |
| CP-04 Program abstraction | recursive and OOP program with tests | can modify design for a new requirement without rewriting everything |
| CP-05 Probabilistic inference & RL | Bayes-net factorization, conditional independence, Bellman/Q-learning example | solve unseen network/gridworld with justification |
| CP-06 Classical ML | regression + classification/cluster analysis | holdout evaluation, baseline comparison, explain overfitting |
| CP-07 Neural networks | forward/backward derivation and from-scratch training | gradients checked conceptually/numerically; loss decreases; report failure modes |
| CP-08 Transformer + generative AI | attention worked example + PyTorch experiment | explain tensor shapes, tokenization, causal mask and evaluation |
| CP-09 Capstone | runnable AI system with README | reproducibility, tests, baseline, metric, privacy/ethics and limitations |

## Periodic review (every 4 *completed* learning weeks)
- Pick **one CS61A** unseen exercise, **one AI Foundations** written/diagram/coding challenge, **one UDL** derivation/explanation; allow 20–40 min each.
- No notes in first attempt. Check correctness, assumptions, interpretation and failure cases.
- Record `PASS / RETRY`, sources of errors and which weeks must be revisited.
- Advance only on evidence. No grades or public self-disclosure needed.

## Private/public
The public repository can show **status** and generic blockers only. Detailed personal reflections, course answers, graded project code and account details should stay private.
