## Operating principles
- A learning week is **a unit of progress, not a calendar deadline**. School assessments take priority; never accumulate “overdue” lessons.
- Default **12–15 focused hours**: ~5–6h CS61A, ~3–4h AI Foundations, ~3h UDL, ~1–2h retrieval/review/math. Temporarily move hours for current coursework.
- **Source first**: read the assigned English text / lecture and attempt exercises independently, then use AI to question or verify understanding.
- Tick `- [x]` only after the specified evidence/checkpoint. Watching a lecture is **not** mastery.
- This public repo stores plans, links, generic rubrics, and public-safe progress only. Keep private reflections, credentials, and submissions elsewhere.
- Do not use AI to generate solutions for graded CS61A exercises; follow each course's academic integrity policy.

## How to study today
1. Open the three track README files; open the next incomplete `Week-XX.md`.
2. Pick a session, open its **direct resource link**, work through the instructions, and attempt its checkpoint.
3. Record what was verified, tick only corresponding checkboxes, commit the Markdown edit.
4. Review with [Checkpoint-Rubric](Progress/Checkpoint-Rubric.md); move forward only when the required exit criteria are met.

No copyrighted textbooks, university solutions, or assignment submissions are stored here.
