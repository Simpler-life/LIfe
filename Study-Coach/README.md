# Study Coach — Cross-conversation Learning Hub

**This directory is the durable handoff for a future ChatGPT conversation.** It defines *how learning is supervised*, not a replacement for the course notes.

## Start here in every new chat
1. Open [HANDOFF.md](HANDOFF.md): instructions for the assistant and exact files to read.
2. Open [STATE.md](STATE.md): current positions in three learning tracks and pending checks.
3. Open [SESSION-PROTOCOL.md](SESSION-PROTOCOL.md): mini-check after each Session/Section, Week-level acceptance, and GitHub write-back.
4. Open [ASSESSMENTS.md](ASSESSMENTS.md): publicly safe checkpoint records (no full graded solutions).
5. Open [CHANGE-PROTOCOL.md](CHANGE-PROTOCOL.md): how to add material without breaking the curriculum.

## What does "- [x]" mean?
- A **reading/practice task** checkbox: the learner actually did that action (self-report is adequate for observable completion, if not claiming mastery).
- An **assessment / PASS** checkbox: only after a mini-check or weekly review demonstrates the required understanding.
- A **Week complete** checkbox: only after all mandatory items + the whole-week assessment pass.
- A failed assessment keeps PASS unchecked, records a focused retry, and does **not** trigger an automatic next week.

**The user initiates a checkpoint** by saying e.g. "CS61A Week 01 Session A 已完成，请小测." The assistant examines the *actual* Week file, asks questions, evaluates answers, then commits eligible ticks and status updates to GitHub. No automatic monitoring of study progress occurs between chats.

## Time budget
12–15 focused hours per learning week across all tracks (see [Study-System](../Learning-Plans/Study-System.md)). A learning week is not necessarily seven calendar days.

> Privacy: this is a public GitHub repository. Store only generic progress and error categories here, never private answers, passwords, student IDs, sensitive logs, or graded solutions.
