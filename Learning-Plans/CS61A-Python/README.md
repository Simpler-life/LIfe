# CS61A — Python & Structure and Interpretation of Computer Programs

**Purpose:** become capable of designing and debugging Python programs independently; not just memorize Python syntax.

## Exact source locations
1. **Course home / schedule / links:** https://lr2933.github.io/cs61a-spring-2026/ — find the lecture title in the schedule, then use its video/slides/readings and linked Lab/Homework/Project pages.
2. **Free textbook:** https://www.composingprograms.com/ — sections 1.1–1.6 (expressions/functions/control/abstraction), 2.x (data), 3.x (programs), 4.x (languages).
3. **Python official tutorial (syntax reference only):** https://docs.python.org/3/tutorial/ — use when syntax is unclear; do not replace course exercises.
4. **Python Tutor:** https://pythontutor.com/ — paste a short self-written function to inspect frames and recursion.
5. **Local tooling:** Windows Python 3.14 may be used initially; if official graders/dependencies reject it, install a compatible second Python environment rather than uninstalling 3.14.

**Video fallback:** some lecture recordings may require UC Berkeley login, even if linked. Use publicly accessible readings, notes and the linked textbook instead; do not bypass access controls.

## How to study each unit
A. Preview the target textbook section for 10–15 min. B. Watch **accessible** relevant lecture or read section actively (trace examples, stop and predict output). C. Run each example by yourself. D. Complete selected Lab/Homework problems **before** asking AI. E. Without notes explain concept and solve a changed example. F. Tick passed boxes and commit.

Avoid copying course solutions or asking AI to write graded answers. CS61A is not only Python: Scheme, SQL and interpreters are part of its computer-science abstraction goals.
