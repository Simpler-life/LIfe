# CS61A — Week 01: Functions, control and environments

**Budget:** 5–6 focused hours, flexible days. **Prerequisite:** C basics are helpful; **Python knowledge assumed:** none.
**Outcome:** write/call/debug small functions, understand `def`, `return`, conditionals, loops and local/global environment.

## Resource locator (open in this order)
1. [CS61A Spring 2026 schedule](https://lr2933.github.io/cs61a-spring-2026/) — locate lectures **Functions**, **Control**, **Higher-Order Functions** and matching Week 1 labs/homeworks. If a recording is private, read textbook instead.
2. [Composing Programs §1.1 Getting Started](https://www.composingprograms.com/pages/11-getting-started.html), [§1.2 Elements of Programming](https://www.composingprograms.com/pages/12-elements-of-programming.html), [§1.3 Defining New Functions](https://www.composingprograms.com/pages/13-defining-new-functions.html), [§1.5 Control](https://www.composingprograms.com/pages/15-control.html).
3. [Python Tutor](https://pythontutor.com/) for step-through; [Python tutorial](https://docs.python.org/3/tutorial/) for syntax reference.

## Session A — first Python programs (~100–120 min)
- [ ] Read textbook §1.1–1.3; write and execute 5 small expressions, 3 functions with inputs/returns.
- [ ] Explain differences from C (`def`, indentation, dynamic types, expression vs statement) using *your own* examples.
- [ ] Attempt the **first accessible** relevant CS61A Lab problems independently; run provided tests if available.
- [ ] **R check**: without notes explain function call, parameters/arguments, `return` vs `print`.

## Session B — conditionals and loops (~100–120 min)
- [ ] Read §1.5 and view the matching accessible Control lecture/notes.
- [ ] Write a function with `if/elif/else` and another with `while`; trace at least two edge cases each.
- [ ] Attempt 2 accessible introductory course problems without copying answers.
- [ ] **T check**: explain why changing a `return` into `print` breaks one caller; demonstrate on a new input.

## Session C — environments + review (~100–120 min)
- [ ] Read [§1.4 Designing Functions](https://www.composingprograms.com/pages/14-designing-functions.html) and preview higher-order functions in course schedule.
- [ ] Trace 2 nested function calls by hand; verify them in Python Tutor.
- [ ] **P check**: independently solve 2 *new* problems involving arguments, conditionals and loops (e.g. valid-score calculator, number property predicate), including normal and boundary tests.
- [ ] Explain your solution aloud (prefer English), then ask ChatGPT for an **oral check with altered examples**, not solutions.
- [ ] Mark Week 01 PASS only if R/P/T checks were met; otherwise write one concrete retry topic.

## Evidence / exit gate
- [ ] At least 2 working original Python functions, with test cases.
- [ ] Correct hand-drawn environment trace and no confusion between print and return.
- [ ] Can modify one function's requirement without step-by-step assistance.
- [ ] Week 01 assessment **PASSED** after independent attempt + feedback.

**Next:** Week 02 higher-order functions, environments and Hog start. Do not rush to recursion unless function calls are comfortable.
