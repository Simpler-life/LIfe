# Understanding Deep Learning — Learning Plan

**Textbook:** Simon J. D. Prince, [Understanding Deep Learning](https://udlbook.github.io/udlbook/)

## Learning agreement

- **Three sessions per learning week**, on any days you choose. A learning week is a unit of progress, not a strict calendar deadline.
- Aim for **40–60 minutes** per session, adjusting to your energy and coursework.
- **Independent learning first:** read the original English text or watch relevant English videos before discussing it with ChatGPT.
- **Theory + practice:** learn concepts and mathematics, then use examples, diagrams, exercises, or Python experiments when useful. Not every session requires coding.
- **Assessment after learning:** answer questions in your own words. ChatGPT checks conceptual understanding, application, and English expression separately, with follow-up questions when needed.
- Advance when the essential concepts are understood. If a session is difficult, extend it instead of rushing or doubling missed work.
- Use English for source materials and initial explanations; Chinese is welcome for clarifying difficult ideas.
- Keep assessment answers and any personal reflections out of this public repository unless you intentionally want to publish them.

## Workflow

1. Open the current `Week-XX.md` and choose any one unfinished session.
2. Read or watch independently; tick completed Markdown tasks by editing `- [ ]` to `- [x]` and committing.
3. After the session, send your understanding or answers to ChatGPT for assessment.
4. Only mark **assessment passed** when you've actually received feedback and addressed essential misunderstandings.
5. When all three sessions and the weekly review are completed, create the next week's plan together.
